# Nova Studio

A modern responsive frontend landing page ready for GitHub and Netlify.

## Run locally

Open `index.html` in your browser, or use a local server if you prefer.

## Deploy to Netlify

1. Push this folder to GitHub.
2. In Netlify, choose **Add new site** → **Import an existing project**.
3. Connect your GitHub repo.
4. Leave the build command empty.
5. Set publish directory to `.`.
6. Deploy.

## Customize

- Edit the text in `index.html`.
- Adjust colors and spacing in `styles.css`.
- Update interactions in `script.js`.
